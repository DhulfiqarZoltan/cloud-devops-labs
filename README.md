# Cloud DevOps Labs

**Author:** Dr. Alwahab Dhulfiqar Zoltan

Practical laptop labs by Dr. Alwahab Dhulfiqar Zoltan for university IT and cloud computing students. Use a disposable Linux environment. No cloud subscription is required for the first six labs.

## Start the Linux practical lab

1. **[Download the student lab ZIP](https://github.com/DhulfiqarZoltan/cloud-devops-labs/raw/refs/heads/main/linux-permissions-lab.zip)**.
2. Extract it into your **Linux home directory**, giving you `~/linux-permissions-lab/app.py`.
3. Follow the [setup and command-by-command guide](01-linux/README.md). Try the exercise before opening [its solution](01-linux/SOLUTION.md).

The ZIP contains the runnable application, full instructions, a separate exercise solution, and the author/license notice. Use Ubuntu 24.04 in a disposable VM or WSL2, with Python 3, curl, and your own sudo account. The permissions practical video and Short are available on the channel.
